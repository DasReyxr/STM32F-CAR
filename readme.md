# STM32 Cars
This repository contains code and resources for 
* Car Controlled by RadioFrequency (RF) Remote
* Car Line Follower Controlled by Fuzzy Logic and IR Sensors.
Both projects are designed to demonstrate the capabilities of STM32 microcontrollers in automotive applications, showcasing the integration of various sensors and control algorithms.
